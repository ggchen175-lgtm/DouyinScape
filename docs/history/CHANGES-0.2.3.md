# 0.2.3：壁纸聊天仅控件变色，父容器透明

包：`../DouyinUnified-0.2.3-transparent-composer-compat.apk`。versionCode=4，包名 cn.zhe.douyinunified，覆盖安装，签名沿用旧版。

SHA256：`28D0955F51FE2B0EDCF84BDBFA4FE928886C281BCE1F0C312A3A626967D87F65`。

## 最新需求更正

用户指出 iOS 自定义壁纸聊天的底栏只有输入框、快捷按钮等控件自身变色，其余区域透明。0.2.2 将整块遮罩连续延伸的做法不符合该需求，本版撤掉壁纸页的整块背板和导航区补绘。

## 代码调整

- UnifiedModule 使用进程共享 AtomicBoolean 去重。真机旧 PID 21124 在同一时间重复初始化主题、聊天注册等；去重后的 PID 24020 仅出现一次模块初始化记录。此修正消除重复 hook/观察器，但没有做隔离性能 A/B，不能据此量化性能提升。
- ChatBottomSurface：自定义壁纸页面不创建 Surface 或 decor/navigation overlay；jak、同尺寸包装层和宽幅平面子背板透明；保留圆角输入框 bmj、快捷按钮、图标等自身的主题背景。原生壁纸和全页夜间调暗由抖音自己绘制。
- 非壁纸禁言群聊保留禁言栏自身原生主题底色，并延伸同一背景至导航区；这不是壁纸页遮罩。
- ChatStatusBackdrop 改为更新原生 ud9 状态栏占位视图，随聊天页移动与销毁；不再使用覆盖整个窗口顶端的 Drawable。返回消息页保持窗口状态栏透明，使用消息页自己的背景。
- ChatScrollControlFix 将按钮避让从禁言群聊扩展至普通私聊、标准群聊；移动 te0 容器，保留原生 te1/tez 资源。普通聊天实测按钮原位置与抬升后的底栏重叠17px，新位置在底栏上方。
- 添加 RuntimeChatDiagnostics：仅有 android.permission.DUMP 的调用者可以通过广播主动采集坐标、padding、translation、背景类型/颜色。无消息正文、无常驻采集、无逐帧文件写入。

普通聊天56px、键盘额外68px、首页、直播、视频T5几何逻辑未改参数。未改视频viewport或Surface尺寸。

## 仍需处理的限制

1. 主题主流程仍重建Activity，可能短暂重载头像/内容，尚未达到iOS完全原地更新的表现。
2. 高刷请求保持165Hz；窗口请求不等于实际应用FPS。0.2.2的一次静止显示快照为90Hz；混合操作gfxinfo有13.41% janky frames，没有原包/旧包隔离对照，因此不宣称已稳定165FPS或卡顿全部解决。
3. 抖音侧设置Provider读取曾返回Unknown authority并回退三项默认开启；shell能读到Provider。三开关跨包读取仍需单独修复，未在本版改变其实现。

本版针对底栏透明和已定位的组件几何问题交付，不能宣称与iOS所有细节完全一致。
