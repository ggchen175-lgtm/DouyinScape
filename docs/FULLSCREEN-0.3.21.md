# 0.3.21 放大播放沉浸修正

将原生视频播放视口延伸至屏幕底部，释放放大状态下首页的底部占位；原生播放按钮单独避让导航区域。退出放大后恢复首页占位和视口尺寸。

使用实际窗口尺寸、导航 Insets 与原生容器坐标，不使用机型固定偏移。适用于命中相同 VideoPinchView、RTViewPager 和 BottomSpace 结构的播放场景。

实机验证：OnePlus 15 / Android 17 / 抖音 40.8.0。放大时视口由 1272×2544 延伸为 1272×2772，画面覆盖小白条背景；退出后恢复视口 1272×2544、首页底部 padding 56、BottomSpace 172。其他机型尚未逐一实测。
