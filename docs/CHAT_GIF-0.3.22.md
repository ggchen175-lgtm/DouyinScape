# 0.3.22 聊天表情推荐栏修正

聊天输入“你好”等文字触发的 GifSearchPanelLayout 是输入框外的独立容器。原先仅抬高输入框，造成推荐表情底部被遮挡。

现在在 ChatDockGeometry 中按推荐栏原生底边与输入框顶边的实际重叠量同步避让，最大不超过当前导航预留量。已在输入框内部的推荐栏不重复处理；隐藏或解除绑定后恢复模块设置的位移。没有新增机型固定高度。

OnePlus 15 / Android 17 / 抖音 40.8.0 实测：推荐图片底边1424与输入框顶边1424对齐，232像素高的表情完整显示；收起键盘后推荐栏关闭、输入框恢复底部位置。未发送文字或表情。保留0.3.21放大播放沉浸修正。
