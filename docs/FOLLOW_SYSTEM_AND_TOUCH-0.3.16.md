# 0.3.16：快速下拉触摸与 40.8 全局跟随系统

## 根因

主题模块在版本入口仅允许 40.7.0；当前手机为 40.8.0，日志显示初始化直接退出，所以热切换失效不限于某个页面。40.8 的主界面 delegate 获取方法、标签恢复路由与个人页 KMP 数据模型也均已变化，不能只放开版本判断。

快速下拉按钮原来依赖原生滑动容器分发触摸。输入区避让后按钮视觉位置已变，惯性滚动时首个触摸可能被原生列表消费；短暂淡出的快照也没有可点击的原生可见区域。

## 修改

- ChatFloatingTouch 仅登记当前聊天根节点，仅在实际圆形按钮或正在淡出的按钮区域内接管手势。按下先停止消息列表惯性滚动；抬起未超过触摸阈值时调用原生按钮的 performClick。其他区域不接管，按钮区域拖动也不触发点击。
- 保留已有 8dp 阴影避让、200ms 进入及160ms退出动画。淡出可见阶段同样支持点击；切换会话或销毁恢复触摸状态并释放登记。
- 对安装包实检 40.8 的 AppCompatDelegate 默认模式字段/设置方法、TiktokSkinHelper 资源更新与查询方法，恢复配置回调、资源同步与 Activity 刷新队列。
- MainActivity 的 delegate 获取方法按40.7/40.8分别为u/t。40.8 的主标签恢复改为在原生底栏宿主内定位标签并调用其原生点击，再以 currentShowTab 确认恢复，不调用旧版 X.0gvU/bm。
- 个人页 CardCellViewModel 仍使用 n 的状态流；40.8 状态类更新为 X.0MMY，20参数/字段布局已检查，文字渲染帮助类为 X.0MMW。迁移了五个快捷入口的图标状态与 Compose 文字颜色处理。
- 40.7 的其他混淆业务渲染补丁未强行套用40.8；全局主题入口不再依赖这些旧版补丁是否安装成功。原生40.8主题为主，迁移过的专用修正单独启用。

## 验证

已安装最终0.3.16。最终进程中连续两次快速滑动后点击按钮，日志均为 floating native click dispatched=true。保留实际聊天根，未跳转到消息里的视频。未发送消息。

在不杀抖音进程的情况下，系统浅深色双向切换已验证：消息列表、聊天会话、个人页、观看历史进入的视频详情。个人页五个快捷入口深色图标/文字可读，浅色恢复；标签恢复日志确认停留在原标签，聊天切换后恢复同一会话。详情页资源 uiMode 分别为33和17。系统模式已还原到测试前的 auto。

按钮的原生 LayerDrawable 和箭头随聊天页重建/主题资源更新；不再因主题入口被40.8版本门槛禁用而失效。导航栏继续透明，原生背景延伸到小白条。

覆盖的是上述实测页面和当前40.8包；未宣称所有远端页面变体、所有40.7专属绘制补丁都已迁移。

源码包不含设备日志、聊天内容、截图、抖音原始APK和签名私钥。异机构建需调整Gradle签名路径。
