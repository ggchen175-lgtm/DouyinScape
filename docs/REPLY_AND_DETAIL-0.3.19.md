# 0.3.19：回复区主题与私信视频底部布局

## 修改

- 聊天行内回复不再依赖旧版数字 dock ID 或 xju/bmj 容器名；在当前聊天输入区中根据 tv_hint 与关闭按钮的共同祖先定位引用容器，从编辑框祖先定位圆角输入背景。
- 保留聊天页本身的浅深色背景及原生圆角、壁纸透明策略；不新增抬高、覆盖层或修改引用正文。
- 原有共享视频安全区适配同时识别公开评论编辑框和私信 SearchableEditText。确认二者与 RTViewPager/BottomSpace 处于同一原生视口后，由共同父级保留实际导航 Insets，让合集、进度条及回复栏一起参与原生测量。
- 键盘出现时让原生输入处理接管；退出键盘后重新计算缺口。旧单控件平移路径在共享父级接管后释放，避免双重补偿。
- 保留其他维护者的 0.3.18 首页实测缺口补偿与 ModuleVersion 改动；没有改写 HomeTabSafeArea。

## 实机验证

设备：OnePlus 15、Android 17、抖音 40.8.0；实际屏幕 1272×2772，当前导航 inset 为56px。56仅为本机测量结果，新增逻辑没有按该值写死。

- 修复前，同一私信视频的合集底边2600、回复栏顶边2562，重叠38px；进度条绘制中心也进入回复栏。
- 修复后，共享原生视口 paddingBottom=56，合集底边2544、回复栏顶边2562，恢复18px原生间距；回复栏 translationY=0，进度条位于回复栏上方。
- 检查了同一视频打开私信回复键盘、关闭输入弹层，以及聊天引用回复的键盘展开和收起；未发送消息。
- 深色聊天引用区背景与页面统一，浅色恢复 #efefef、输入区为白色；回复关闭后普通输入背景正常。
- 浅深色测试后恢复系统自动模式及当前深色激活状态。
- 最终 APK 已安装，保留包名和签名。无 System UI 重载。

## 范围

本次独立验证的是上述真机与原生布局。保留了 0.3.18 的模拟器测试记录，但未在本次重做该测试，也不代表所有厂商 ROM 已验证。源码包不含设备日志、聊天截图、原始抖音 APK、签名材料或本地诊断工具。
