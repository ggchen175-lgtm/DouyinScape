# 抖境 · DouyinScape

面向抖音 Android 客户端的 Xposed / LSPosed 体验增强模块。

抖境围绕手势导航沉浸、系统主题同步和聊天界面协调展开适配，尽量复用原生布局与交互，使内容自然延伸到系统栏区域，同时为输入栏和操作按钮保留必要的安全空间。

## 功能

- **手势导航沉浸**：适配首页、消息、聊天、评论、视频与图文详情，以及已验证的音乐、玩法挑战、听抖音等页面容器。
- **系统主题同步**：跟随系统浅色与深色切换，协调资源、窗口与页面生命周期；部分页面通过重建恢复主题与会话状态。
- **聊天界面协调**：统一输入区、消息列表和浮动按钮的几何关系，处理键盘、面板避让及快速回到底部按钮的动画与触摸。
- **刷新率请求**：请求当前分辨率下可用的最高显示刷新率，保留原有分辨率；不保证实际渲染帧率。
- **可选私信通知头像**：在系统界面中使用抖音通知携带的联系人头像；失败时保留原图标。

通知堆叠属于独立模块，不包含在本项目中。

## 安装与使用

1. 安装模块 APK，在 LSPosed 中启用并勾选抖音。
2. 打开桌面“抖境”，按需设置三个功能开关；抖音内主题选择“跟随系统”。
3. 停用作用相同的旧沉浸、主题模块，彻底关闭后重新打开抖音。
4. 如需通知头像，另外勾选 System UI，并重新加载系统界面；这可能触发锁屏。

同签名模块 APK 可覆盖更新。自行构建使用自己的签名，不能直接覆盖官方签名版本；更换签名前请自行备份设置。

## 构建

环境：JDK 17、Android SDK 34、Gradle 8.7（已提供 Wrapper）。

```sh
./gradlew :app:assembleDebug
```

Windows 使用 `gradlew.bat :app:assembleDebug`。首次构建需要联网下载 Gradle 与依赖。默认使用本机 Android 调试签名；自定义签名通过以下环境变量提供：

- `DOUYINSCAPE_KEYSTORE`：本机签名文件路径。
- `DOUYINSCAPE_STORE_PASSWORD`、`DOUYINSCAPE_KEY_ALIAS`、`DOUYINSCAPE_KEY_PASSWORD`。

签名私钥与密码不得提交到仓库。构建产物位于 `app/build/outputs/apk/debug/`。

## 数据与网络

模块不提供遥测或消息上传服务。可选头像功能可能向通知中已有的头像地址发起下载请求。几何诊断仅在具有 Android DUMP 权限的请求下运行，结果留在抖音私有目录，不记录消息正文或图片。报告问题时请自行遮盖截图、日志中的个人信息。
